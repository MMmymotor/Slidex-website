# 📚 Index Documentation - Diagnostic Vidéo SlideX

## Vue d'ensemble du projet

Le diagnostic vidéo est un nouveau service SlideX permettant aux clients avec une porte automatique en panne d'obtenir un diagnostic professionnel en visioconférence pour 19€ TTC (déduit si intervention via Expert SlideX).

**Zone MVP :** Grenoble + 40 km  
**Engagement :** Sous 24h ouvrées  
**Durée :** 10-12 minutes
